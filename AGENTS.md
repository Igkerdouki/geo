# AskGaia collaboration

- Ved/Codex owns application logic, backend APIs, MCP tools, data integration, database work, and tests.
- Ioanna owns UI, visual design, layout, typography, and frontend presentation.
- Preserve Ioanna's UI work. Do not redesign or restyle it unless Ved explicitly requests it; frontend logic changes should preserve its presentation.
- Inspect the latest remote branch before integrating changes. Preserve teammates' commits and use non-force updates; do not overwrite main with an older local snapshot.
- Never commit .env files, credentials, local databases, dependency folders, or build output.
- Keep recorded pesticide use, modeled scenarios, and measured exposure distinct.
